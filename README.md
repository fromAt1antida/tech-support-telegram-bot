# Telegram Support Bot

Телеграм-бот для поддержки клиентов интернет-магазина **TechZone**.

## Описание
Это учебный проект — телеграм-бот для общения с клиентами магазина электроники.
Бот отвечает на частые вопросы и принимает обращения пользователей.

## Возможности бота
- ответы на часто задаваемые вопросы
- приём сообщений от клиентов
- передача вопросов в нужный отдел
- сохранение обращений

## Отделы поддержки
- Технический отдел — проблемы с сайтом и оплатой
- Отдел продаж — вопросы по товарам и заказам

## Используемые технологии
- Python
- Telegram Bot API

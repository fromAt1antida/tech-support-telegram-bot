# Telegram Support Bot

Телеграм-бот для поддержки клиентов интернет-магазина  
«Продаем всё на свете!»

## Описание
Это учебный проект — телеграм-бот, который помогает клиентам.
Он отвечает на частые вопросы и принимает обращения, если ответа нет.

## Что умеет бот
- отвечает на часто задаваемые вопросы
- принимает сообщения от пользователей
- передает вопросы в нужный отдел
- сохраняет обращения

## Отделы
- Программисты — проблемы с сайтом и оплатой
- Отдел продаж — вопросы по товарам

## Технологии
- Python
- Telegram Bot API
